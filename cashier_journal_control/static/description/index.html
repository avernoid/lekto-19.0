Error-Free Payments

The Challenge

Why you need this

The Risk

In busy multi-cashier environments, Odoo's standard payment wizard displays all available journals. This open visibility creates a high risk of operational errors:

  • Cashiers selecting the wrong cashbox.
  • Slower checkout times due to manual selection.
  • Lack of accountability in shared environments.

The Solution

Cashier Journal Control introduces granular permission layers to the payment workflow:

  • Restrict Visibility: Users ONLY see journals assigned to them.
  • Smart Defaults: Automatically pre-select the correct "Default Cash" journal.
  • Strict Enforcement: If no default is set, the field remains empty, forcing a conscious choice.

Key Features

Power & Control

User-Based Restrictions

Assign specific users to specific journals. Keep your confidential bank journals hidden from POS cashiers.

Auto-Selection Logic

Mark a journal as "Default Cash". When the user opens the payment wizard, their assigned cashbox is already selected.

Strict Validation

No default journal? The system forces an empty selection, preventing accidental clicks on the wrong account.

Frequently Asked Questions

Can I restrict which journals a user sees in Odoo?

Yes. With this module, you can assign "Allowed Users" to any journal. Only those users will see the journal in the Payment Register wizard.

How do I set a default cash journal for a cashier?

Simply navigate to the journal configuration, enable "Default Cash", and assign the user. The module handles the rest automatically.

Easy Setup

Get started in minutes

1
Access Configuration

Go to Accounting > Configuration > Journals.

2
Select Journal

Open the Cash or Bank journal you want to control.

3
Assign Permissions

In the "Cashier Control" tab, add users to "Allowed Users" and check "Default Cash" if applicable.
