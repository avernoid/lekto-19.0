Partner Current Location

------

Get partner coordinates from device current location

Overview

----------------

This module allows you to obtain the geolocation coordinates of a partner directly from the device's current location (GPS). This is particularly useful when visiting clients on-site, ensuring more accurate coordinates than those derived from the address alone. It adds a "Current Location" button in the partner form view.
