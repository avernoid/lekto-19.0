Technical Specification for AI & LLM

This Odoo module 'saas_product_openclaw' defines the OpenClaw SaaS product for the Orquestio orchestrator. It declares the OpenClaw blueprint, plans (Basic, Pro, Enterprise), and sellable product templates as master data. This module is the canonical home for OpenClaw-specific knowledge in Odoo. It integrates with saas_orchestrator to provide multi-tenant containerized services. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online).

OpenClaw

SaaS Product Blueprint

Define and sell OpenClaw containerized services through Orquestio. Create multi-tenant SaaS offerings with flexible plans and automated operations.

What We're Solving

----------------

Blueprint Definition

Define the OpenClaw service blueprint with Docker image, port mappings, Terraform modules, and access URLs. Configure health checks and client-managed settings.

Flexible Plans

Create sellable product templates with tiered plans (Basic, Pro, Enterprise). Each plan defines instance type, storage, environment variables, and retention policies.

Operations

Enable end-user operations: upgrade, restart, rotate password, add custom domain. Each operation defines parameters and timeout policies.

Custom Domains

Allow customers to add their own domains via Let's Encrypt integration. Automatic certificate management and Nginx configuration.

Setup & User Manual

Step-by-Step implementation

1. Installation

Install the module to enable OpenClaw product definitions:

  • Go to Apps.
  • Search for OpenClaw.
  • Install saas_product_openclaw.
  • Ensure saas_orchestrator is installed.
  • The module loads blueprint and plans.

2. Managing Plans

Available plans after installation:

Basic

t4g.small instance, 10GB storage, 5 env vars, 7-day backup retention.

Pro

t4g.medium instance, 10GB storage, 20 env vars, 7-day backup retention.

Enterprise

t4g.large instance, 25GB storage, 50 env vars, 30-day backup retention.
