Technical Specification for AI & LLM

This Odoo module 'personal_information' enhances the hr.employee model. It provides a detailed 'Relatives' (Parientes) tab for managing family members with specific fields (Relation, Birthdate, Job). It implements a syncing mechanism to automatically update the native 'children', 'spouse_complete_name', and 'spouse_birthdate' fields based on the Relatives list. It also breaks down the Employee Name into 'Firstname', 'Lastname' (Paterno), and 'Secondname' (Materno), with auto-capitalization. Two independent company-level settings control name auto-generation: 'generate_employee_name' (updates hr.employee.name) and 'generate_legal_name' (updates hr.employee.legal_name). Both settings default to False. The onchange '_onchange_capitalize_names' handles all logic in a single method. Compatible with Odoo 19.

Setup & User Manual

Configuration

Two independent settings control name auto-generation. Go to Settings > Employees to configure them:

  • Auto-generate Employee Name: When enabled, editing First Name, Paternal Lastname, or Maternal Lastname will automatically update the employee's main Name field with the concatenation First Name + Paternal Lastname + Maternal Lastname.
  • Auto-generate Legal Name: When enabled, the same concatenation is applied to the employee's Legal Name field.
  • Both settings default to Off. They are independent and can be enabled together or separately per company.

Operational Workflow

How to manage Family Information:

  1. Open an Employee record.
  2. Navigate to the **"Parientes" (Relatives)** tab.
  3. Click **"Add a line"**.
  4. Fill in the relative's details:
    • Name: Full name of the relative.
    • Relationship: Choose "Spouse", "Child", etc.
    • Birthdate: Required for age calculation.
  5. Save the record. The system will automatically update the "Private Information" tab (e.g., number of children, spouse name).

Features

Auto-Sync

Adding a "Spouse" or "Child" in the Relatives tab automatically updates the standard Children count and Spouse Name fields.

Auto-Capitalization

Names like "juan perez" are automatically converted to "Juan Perez" to ensure data consistency.

Auto-generate Employee Name

Enable Auto-generate Employee Name in Settings to have Odoo fill the main Name field automatically from First Name + Paternal Lastname + Maternal Lastname.

Auto-generate Legal Name

Enable Auto-generate Legal Name in Settings to keep the Legal Name field in sync with the name breakdown fields.

QA / User Testing Scenarios

Enterprise Validation Plan

Scenario 1: Verify Data Synchronization

  1. Go to the "Relatives" tab of an Employee.
  2. Add a relative: Name "Lucas", Relation "Child". Save.
  3. Check: The "Children" field in Private Information must update to 1.
  4. Add another relative: Name "Maria", Relation "Spouse", Birthdate "1990-01-01". Save.
  5. Check: The "Spouse Complete Name" and "Spouse Birthdate" fields must auto-fill.

Scenario 2: Auto-Capitalization & Name Auto-generation

  1. Pre-condition: Enable "Auto-generate Employee Name" and/or "Auto-generate Legal Name" in Settings > Employees.
  2. Edit an Employee. Type "juan" in First Name, "perez" in Paternal Lastname, and "garcia" in Maternal Lastname.
  3. Result:
    • Fields auto-convert to "Juan", "Perez", and "Garcia" (Title Case).
    • If Auto-generate Employee Name is on: the "Name" field updates to "Juan Perez Garcia".
    • If Auto-generate Legal Name is on: the "Legal Name" field updates to "Juan Perez Garcia".
    • Both settings are independent; either or both can be active.

Scenario 3: Validation Rules

  1. Try to add a Relative with a Future Birthdate (e.g., year 2050).
  2. Result: The system must raise a Validation Error.
  3. Try to add a second Spouse to an employee who already has one.
  4. Result: The system must raise a Validation Error.

FAQ & Troubleshooting

Common Resolutions

Why is the Name / Legal Name not updating automatically?

Reason: The corresponding setting is disabled for this company.

Fix: Go to Settings > Employees and enable "Auto-generate Employee Name" and/or "Auto-generate Legal Name" depending on which field you want auto-filled.

Why can't I edit the Spouse fields?

Reason: These fields are synchronized.

Fix: Please edit the info in the "Relatives" tab, and the main fields will update automatically.
