Employee Personal Information
=============================
Enhances the employee form to allow detailed management of family information/relatives and breaks down the employee names into First and Last names.

Configuration
=============
Go to **Settings > Employees**.
Enable **"Autogenerar Nombre Legal"** (Auto-generate Legal Name) if you want the "Legal Name" field to be automatically populated from the Firstname and Surnames.

Features
========
* **Relatives Tab**: A dedicated tab in the Employee form to add Spouse, Children, and other relatives.
* **Auto-Sync**: Automatically updates the native 'Spouse Name', 'Spouse Birthdate', and 'Children count' fields based on the Relatives tab.
* **Legal Name Breakdown**: Separate fields for First Name, Paternal Lastname, and Maternal Lastname.
* **Auto-Capitalization**: Names are automatically capitalized (e.g., "juan" -> "Juan").
