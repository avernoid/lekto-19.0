Technical Specification for AI & LLM

This Odoo module 'add_user_by_journal' implements granular access control for account.journal records. It extends the Accounting Dashboard and search views to filter records based on 'assign_to_ids' (Users) and 'journal_group_ids' (Groups). Enforces security via ir.rule on account.move, ensuring record-level privacy. Supports Hybrid Security: Public Access if assignments are empty; Restricted Access if Users or Groups are set. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). NOT supported on Odoo Online due to custom code restrictions. Multi-language support for English and Spanish included.

Journal Control

Private Accounting Hub & Group Access

Secure your financial data by restricting journal visibility to authorized team members or groups. Perfect for POS, Multi-Office, and high-security environments.

What We're Solving

----------------

Hybrid Access Control

Maximum flexibility: Assign specific Users AND/OR entire User Groups (e.g., "POS Cashiers") to a journal. The system intelligently unifies permissions, so if a user matches either condition, they get in.

Smart Public Access

Need a public journal for automation or web sales? Just leave the assignments empty, and it automatically becomes Public. Add one user, and it instantly becomes Private.

Setup & User Manual

Step-by-Step implementation

1. Configuration Guide

Prepare the system for secure access in 4 simple steps:

  • Go to Accounting > Configuration > Journals.
  • Select the Bank, Cash, or Misc journal you want to protect.
  • Find the Security Settings.
  • To Restrict: Add Users or Groups. (Hybrid Logic: User OR Group).
  • To Public: Leave both fields empty.
Smart Explainer: Look for the blue (Public) or yellow (Restricted) message box on the form. It will explain exactly who has access in real-time.

2. Operating Manual (Workflow)

How the system behaves for the end-user:

Clean Dashboard

The Accounting Dashboard is now private. Each team member only sees the journals related to their assigned tasks, eliminating clutter and potential data leaks.

Bulletproof Privacy

Security goes deep. Users cannot search for or read Invoices, Moves, or even Journal Items (Lines) that belong to restricted journals. Your sensitive data is locked down at the database level.

Smart Interoperability

Privacy doesn't break operations. The system detects Commercial Data (Payments/AR/AP) and allows Sales to view them on invoices, even if the originating journal (e.g., Bank) is hidden. Smooth workflow, zero leaks.

Fast Navigation

When moving between diaries, users can use the pre-configured "My Journals" (Mis Diarios) filter to instantly narrow down their workspace.

Multi-Currency Support

Journal assignments respect multi-currency configurations and company divisions, ensuring a broad and secure ERP operation.
