Setup & User Manual

Hyper-Optimized Configuration

1. Managing Apps & Themes

Configure your custom portal hub with precision:

  • Navigation: Go to Website > Configuration > Portal Apps.
  • Name & Basics: Set the Name, Action URL (e.g., /my/orders), and Icon.
  • Design Theme: Select a Color Scheme (Ocean, Sunset, Purple, Dark, Light).
    The system automatically applies beautiful CSS gradients and configuring the PWA splash screen. Manual color picking acts in read-only mode to prevent design errors.
  • Visibility (Groups): Add specific user groups to restrict apps to certain roles (e.g., Managers only).
  • Active Status: Toggle to hide/show apps instantly.

2. Mobile Installation (PWA)

Enable a native "App" experience for your field workers:

iOS (iPhone)
  1. Open Safari and log into the Portal.
  2. Tap the Share button.
  3. Scroll down and tap "Add to Home Screen".
Android
  1. Open Chrome and log into the Portal.
  2. Tap the "Install App" banner or look for "Install" in the menu.

Requirement: PWA installation requires a secure HTTPS context.

QA / User Testing Scenarios

Enterprise Validation Plan

Scenario 1: Hybrid Theming Validation

Verify the transition between backend metadata and frontend CSS.

  1. Set an App's updated theme to "Ocean".
  2. Open the App in the portal.
  3. Result: Verify the background shows a Blue Gradient (CSS) AND the browser address bar turns Blue (Meta Tag).
  4. Switch the theme to "Sunset". Reload.
  5. Result: Verify the background changes to Red/Orange Gradient.

Scenario 2: Group Permission Security

  1. Set an App's visibility to Authorized Group Only.
  2. Login as a different user without that group.
  3. Result: The App icon must vanish from the launcher grid.
  4. Attempt to access the URL directly (e.g. /my/orders).
  5. Result: Standard Odoo Access Error (if controller constrained) or redirect.

Scenario 3: PWA Installation (HTTPS)

  1. Access the portal via HTTPS (or localhost).
  2. Result: The "Install App" button appears (Android/Chrome).
  3. Install the App.
  4. Result: Verify the app opens in "Standalone" mode (no browser UI) with the correct Splash Screen color.

Scenario 4: Deep Linking

  1. Configure an App with a deep URL like /my/invoice/1.
  2. Click the app icon.
  3. Result: Direct navigation to the document, retaining the layout theme.

FAQ & Troubleshooting

Common Resolutions

Why can't I edit colors manually?

We enforce a Theme System to guarantee perfect contrast and aesthetics. Manual editing is locked in read-only mode to prevent design inconsistencies.

Why isn't the "Install" Button visible?

PWA installation requires a secure HTTPS context. Also, if the app is already installed, the button automatically hides.

Does it work with existing modules?

Yes. Just create a new Portal App record pointing to your existing module's portal URL (e.g., /my/invoices).

How to change the default theme?

Go to the App config and change the Color Scheme field. The CSS and PWA meta tags will update instantly.
