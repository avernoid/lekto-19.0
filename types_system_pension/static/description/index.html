Technical Specification for AI & LLM

This Odoo module 'types_system_pension' implements a complete Peruvian Pension System catalog for HR and Payroll. It defines the 'pension.system' model with fields for code, name, pension regime, sector coverage (private, public, other), and CUSPP flag. It defines 'comis.system.pension' for storing historical AFP commission rates (fund, bonus, mixed-flow, flow, balance) by date range. It defines 'tope.afp' for storing the AFP monthly limit (tope) applicable by date range. It extends 'hr.employee' with fields: cuspp (CUSPP code), is_cuspp (computed boolean), pension_system_id (Many2one to pension.system), and commission_type (selection: balance/flow). All employee fields are restricted to hr.group_hr_user. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). Multi-language support for English and Spanish included. Requires l10n_pe_localization_menu and hr.

Pension System

Peru AFP & SNP — Complete Payroll Engine

Define all Peruvian pension systems (SNP, AFP), manage commission rates and AFP caps by date range, and assign each employee their pension regime for precise payroll calculations.

What We're Solving

----------------

No Pension Catalog

Standard Odoo does not include a catalog of Peruvian pension systems. This module adds the complete list of SNP and AFP regimes registered in Peru, with all their official codes and attributes.

Commission Rate History

AFP commission rates change over time. This module stores all historical commission rates per pension system by date range (fund, bonus, mixed-flow, flow, balance), ensuring compliance with current regulations.

AFP Monthly Caps

The AFP contribution has a regulated monthly cap (tope AFP). This module allows you to store the cap by date range so the payroll engine can correctly apply limits when calculating AFP deductions.

Employee Assignment

Each employee can be linked to their pension system, CUSPP code, and commission type (balance vs. flow). This data is available to the payroll engine for automatic deduction calculation per worker.

Setup & User Manual

Step-by-Step implementation

1. Configuration Guide

Prepare the pension catalog and limits in 4 simple steps:

  • Go to Localization > Configuration > Pension Systems.
  • Review or add the SNP and AFP systems with their code and sector flags.
  • Under each AFP, add the Commission Rates by date range.
  • Go to AFP Monthly Caps and configure the official cap for each period.
Note: The module ships with pre-loaded Peruvian pension system data. Review the default records and update commission rates as regulations change.

2. Operating Manual (Workflow)

How to assign pension systems to employees:

Employee Tab

Open any employee record and go to the Private Information tab. Assign their Pension System (e.g., AFP Integra, ONP), enter the CUSPP code if applicable, and select the Commission Type (Balance or Flow).

Payroll Integration

During payslip computation, the payroll rules can read the employee's pension_system_id and commission_type to fetch the applicable commission rate and apply monthly AFP caps automatically.

CUSPP Auto-Detection

The system automatically detects if the assigned pension system requires a CUSPP code (the Peruvian pension fund unique identifier) and activates the is_cuspp flag on the employee.

Security & Access

All pension fields on the employee form are restricted to HR Officers only, ensuring sensitive compensation data is not exposed to regular users or portal users.

Global Ready | Multi-Language Support

This module is fully translated into English and Spanish (en_US, es_ES, es_PE, es_MX), ensuring a professional experience for international organizations.

FAQ & Troubleshooting

Common Resolutions

Pension fields not visible on employee?

Reason: The user does not have the HR Officer role.

Fix: Go to Settings > Users and assign the Human Resources / Officer group to the user.

CUSPP Active flag not computing?

Reason: The assigned Pension System does not have the CUSPP checkbox enabled.

Fix: Edit the Pension System record and enable the CUSPP checkbox to activate automatic detection.

Commission rate not applying in payroll?

Reason: The payroll rule references the commission but no rate record exists for the current period.

Fix: Add a commission entry under the AFP system with a date range that covers the payroll period.

Is this compatible with Multi-company?

Answer: Yes!

Detail: Pension system records are company-agnostic by default. Each employee assignment is per-employee and respects multi-company environments.
