# Account Invoice Extras

**Author**: [Ganemo](https://www.ganemo.co)

![Banner](/account_invoice_extras/static/description/banner.png)

## Overview
This module consolidates multiple invoicing enhancements into a single, cohesive package. It allows companies to manage extra reference data and communicate better with customers via printed invoices.

## Features
- **Carrier Reference Number**: Store the "Guía de Remisión" or carrier tracking number directly on the invoice form.
- **Additional Document Reference**: A flexible field for any external document reference (Purchase Orders, Contracts, etc.).
- **Printed Invoice Comments**: Configure company-wide text or HTML content (tables, terms) that automatically appears on every printed invoice PDF.

## Configuration

### Setting up Printed Comments
1. Go to **Settings > Users & Companies > Companies**.
2. Select your company.
3. Open the **"Información Adicional Factura Impresa"** tab.
4. Enter your custom text, tables, or terms in the WYSIWYG editor.
   - *Note*: This content will appear at the bottom of the invoice PDF, respecting your formatting.

## Usage

### On Invoices
1. Open any Customer Invoice.
2. The **Carrier Ref Number** field is located near the Payment Reference.
3. The **Additional Document Reference** is located in the "Other Info" tab.
4. Input your data and save. These fields are preserved permanently.
