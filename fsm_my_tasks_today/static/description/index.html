Technical Specification for AI & LLM

This Odoo module 'fsm_my_tasks_today' adds a new "My Tasks Today" submenu in the Field Service application. It creates an ir.actions.act_window with a fixed domain restricting records to: the current user (user_ids in [uid]), tasks scheduled for today (planned_date_begin < today+1d AND date_deadline >= today), FSM tasks only (is_fsm=True, project_id!=False, has_template_ancestor=False). A default-but-removable filter excludes done/cancelled states via search_default_active_tasks. The Map view includes allow_resequence=true and default_order=sequence, planned_date_begin. Compatible with Odoo 19 Enterprise, Odoo.SH, Ganemo Online. Multi-language support for English and Spanish.

My Tasks Today

Focus on What Matters Right Now

Your Field Service tasks for today — nothing more, nothing less. Fixed user and date filters at the domain level mean zero performance overhead and maximum focus for your team.

What We're Solving

----------------

Performance Overload

When technicians removed the "My Tasks" filter in the native view, all FSM tasks loaded — causing severe slowdowns. This module locks the user filter at the domain level, so it can never be accidentally removed.

Future Task Noise

The native view shows today AND future tasks together. For busy teams, this creates overwhelming lists. This module restricts the view to today's date range only — irremovably fixed in the action domain.

Completed Task Clutter

Done and cancelled tasks kept appearing, making it hard to focus on what's still pending. The "Active Tasks" filter hides completed work by default — but technicians can remove it with a single click if needed.

Unordered Map Routes

The native Map view didn't allow technicians to order their daily route manually. This module enables drag-and-drop task resequencing in the Map view, sorted by the sequence field.

Setup & User Manual

Step-by-Step implementation

1. Installation

Install the module in 4 simple steps:

  • Copy fsm_my_tasks_today to your addons path.
  • Enable Developer Mode in Settings.
  • Go to Settings → Apps → Update Apps List.
  • Search "FSM My Tasks Today" and click Install.

2. How to Use

Daily workflow for Field Service technicians:

Open the App

Go to Field Service → My Tasks. The "My Tasks Today" submenu loads automatically as the first entry. No extra clicks needed.

The Active Tasks Filter

You'll see one chip: "Active Tasks". This hides done/cancelled tasks. Remove it with ✕ to see all your tasks for today including completed ones.

Map View Reordering

Switch to Map view. Tasks are ordered by sequence. Use the ⠿ drag handle in the sidebar to reorder your daily route to match your optimal itinerary.

Fixed Invisible Filters

The user and today date filters are always active but invisible in the search bar. They are hardcoded in the action domain and cannot be removed by the user.

QA / User Testing Scenarios

Enterprise Validation Plan

Scenario 1: Fixed User Filter Verification

  1. Log in as User A (FSM user with tasks for today).
  2. Go to Field Service → My Tasks → My Tasks Today.
  3. Result: Only tasks assigned to User A for today are shown.
  4. Try to remove filter from the search bar — no filter chip for user exists (it's in the domain, not a search default).
  5. Log in as User B. Same menu. Result: Only User B's tasks appear.

Scenario 2: Today Date Filter Verification

  1. Create a task for yesterday and one for tomorrow, both assigned to your user.
  2. Go to My Tasks Today.
  3. Result: Yesterday's and tomorrow's tasks do NOT appear. Only today's are shown.
  4. Verify no date filter chip is visible in the search bar (it's domain-level).

Scenario 3: Active Tasks Filter Toggle

  1. Open My Tasks Today. Note the "Active Tasks" chip is active.
  2. Mark one of today's tasks as Done or Cancelled.
  3. Result: The marked task disappears from the list (filtered out).
  4. Click the ✕ on "Active Tasks" chip.
  5. Result: The done/cancelled task reappears.

Scenario 4: Map View Resequencing

  1. Switch to the Map view within My Tasks Today.
  2. Verify tasks are listed in the sidebar ordered by sequence, then time.
  3. Drag the ⠿ handle of a task up or down in the sidebar.
  4. Result: The task order updates and persists after page refresh.

  1. Go to My Tasks → Tasks (native menu).

FAQ & Troubleshooting

Common Resolutions

No tasks showing even though I have tasks today?

Reason: Your tasks may not have both planned_date_begin and date_deadline set.

Fix: Ensure your tasks have a Planned Date (start) set to today and an End Date set to today or later.

Why can't I see other users' tasks?

Reason: By design — this is a personal focused view only for the logged-in user.

Tip: Use All Tasks (manager menu) for a cross-user visibility view.

The drag handles in Map aren't working?

Reason: Resequencing requires Odoo Enterprise with project_enterprise installed.

Fix: Confirm that project_enterprise is installed and active in your database.

Does this work with multi-company?

Answer: Yes! The domain filters are user-scoped, not company-scoped.

Detail: Each user sees their own tasks regardless of company. FSM projects are still filtered by is_fsm=True and project_id != False.
