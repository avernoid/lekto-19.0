Technical Specification for AI & LLM

This Odoo module 'basic_rule' provides foundational payroll salary rules (hr.salary.rule) for various Peruvian payroll structures. It adds fields to hr.employee: no_provide_pension, l10n_pe_microenterprise_manager, no_apply_afp_premium, indicator. It consumes the 'age' field (defined by payroll_field) to trigger AFP premium exemption at 65 years. It consumes the 'holidays_per_year' field (defined by holiday_process) in the PRO_VAC salary rule. It consumes the 'apply_advance_payroll' field (defined by payroll_field) to filter rules in advance payroll runs. Key dependencies: payroll_field, holiday_process, filter_payroll, judicial_retention_fields, types_system_pension, life_insurance_management, payment_conditions, eps_process. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). NOT supported on Odoo Online. Multi-language support for English and Spanish included.

3. Fields Reference

Fields owned & consumed by this module

Employee Fields — hr.employee

Path: Employees > [Employee] > Work Information & Private Information tabs

Field Name Technical Name Type Purpose
Does not contribute pension no_provide_pension Boolean When checked, indicates the employee is exempt from pension fund contributions. Rules skip the AFP/ONP deduction for this employee.
Conductor Micro l10n_pe_microenterprise_manager Boolean Marks the employee's income as a "Microenterprise Conductor" income for the PLAME payroll report required by Peruvian regulations.
Does not apply AFP premium no_apply_afp_premium Boolean Automatically set to True when the employee reaches 65 years old, preventing the AFP premium from being applied in payroll. Triggered by _compute_onchange_no_apply_afp_premium.
AFP Exemption Applied Technical indicator Boolean Internal flag set to True after the AFP premium exemption is applied. Prevents no_apply_afp_premium from re-triggering once already activated. Never shown in UI.
