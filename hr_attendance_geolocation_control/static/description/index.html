Attendance Geolocation Control

Advanced Geofencing & Location Validation for Odoo 19

Elevate your HR security with high-precision geolocation tracking. Prevent attendance fraud, enforce strict site policies, and ensure every check-in is verified through advanced Haversine validation algorithms.

What We're Solving

----------------

Attendance Fraud Prevention

Eliminate "proxy" check-ins and remote clocking by enforcing a strict geographical radius. Ensure employees are physically present at assigned work sites before they can start their day.

Remote Compliance

Manage hybrid workforces with confidence. Automatically differentiate between office sites and telecommuting locations, applying specific validation rules for each scenario.

Module Overview

----------------

A seamless extension to Odoo Attendance. No new buttons, no disruption. Our backend-heavy logic captures device coordinates and GPS accuracy to perform real-time verification against HR-defined Work Locations.
Geofencing

Custom radius control down to the meter for every office or job site.

Accuracy Policy

Filter low-quality GPS signals to prevent spoofing or accidental errors.

Enforcement

Flexible policies: Block actions, warn users, or require mandatory justifications.

Precision Configuration

----------------

HR Data Centralization: Configure coordinates directly within Odoo's native Work Location records. Set manual latitude/longitude values and define distinct accuracy thresholds (High, Medium, Low) to match your organizational security standards. Supports full multi-company fallback logic via System Defaults.

Workflow Guide

----------------

01 Employee Check-in

User clicks the standard Odoo Check-in. The system silently captures data. If valid, process continues; if not, the configured policy (e.g., Mandatory Reason) triggers immediately.

02 Manager Audit

Detailed attendance logs show distance from target, GPS reliability status, and location badges for easy auditing and compliance reporting.
