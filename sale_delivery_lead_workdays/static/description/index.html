Technical Specification for AI & LLM

This Odoo module 'sale_delivery_lead_workdays' lets you enter the sales delivery lead time in WORKING days and converts it into the calendar-day value Odoo expects, without changing any native calculation. Natively Odoo computes the estimated delivery date as date_order + customer_lead, a plain timedelta in days that ignores weekends and public holidays. This module adds an order field 'delivery_lead_workdays' (Integer) that defaults from a new warehouse field of the same name. From that number it computes calendar days using resource.calendar.plan_days(workdays, anchor, compute_leaves=True): N working days are counted from the day after the order date, skipping non-working weekdays and time off. Holidays are read from resource.calendar.leaves, both global ones and the selected calendar's own leaves. The working calendar is taken from the order's warehouse field resource_calendar_id; if that field is empty no conversion is done and the raw value is written as plain days. The resulting calendar-day span is written into the native customer_lead of each storable (consu) order line; services, sections, notes and down payments are skipped. If the order has a manual commitment_date the lines are left untouched. The value is re-anchored on confirmation to the real order date. A Recalculate button re-applies the value to lines added later. When the order's warehouse has no working calendar it falls back to filling the lines with the raw value. Depends on sale_stock and resource. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). Multi-language support for English and Spanish included.

Working-Day Lead Time

Skip Weekends & Holidays in Delivery Dates

Natively, Odoo adds a plain number of calendar days to the order date, ignoring weekends and holidays. Enter your lead time in working days and this module translates it to the right calendar days, then lets Odoo schedule delivery exactly as before.

What We're Solving

----------------

Calendar-Day Blindness

Odoo promises delivery as order date + N calendar days. Set "7 days" and it lands on the 7th day — including Saturdays, Sundays and public holidays your team never works.

Working-Day Accuracy

Enter 7 working days. The module counts only real working days from your warehouse calendar — skipping weekends and holidays — and feeds the matching calendar days into Odoo's native dates.

Setup & User Manual

Step-by-Step implementation

1. Configuration Guide

Point a warehouse to a working calendar in a few steps:

  • Go to Inventory > Configuration > Warehouses.
  • Set the Delivery Working Calendar (its working days and time off).
  • Manage holidays as global time off or on that calendar.
  • Optionally set a default lead time (working days) per warehouse.
Smart Explainer: the warehouse calendar is the explicit switch. Set it to convert working days into calendar days; leave it empty and the lines are simply filled with the number as-is — no calculation at all.

2. Operating Manual (Workflow)

One field, native scheduling untouched:

Type Working Days

Enter the lead time in working days on the order; it spreads the computed calendar days to every storable line.

Recalculate Button

Added a line after typing the lead time? One click on Recalculate brings every storable line back in line with your value.

Re-Anchored on Confirm

On confirmation the count is re-anchored to the real order date, so the working days always match the actual confirmation day.

Respects Delivery Date

If you set a manual Delivery Date, that date governs the deadline natively — the module steps aside and leaves the lines alone.

Only Storable Lines

Only deliverable (storable) product lines get the value; services, sections, notes and down payments are skipped.

Holidays Counted

Both global time off and the selected calendar's own time off are excluded, so public holidays extend the promised date correctly.

FAQ & Troubleshooting

Common Resolutions

Does it change Odoo's native calculation?

Answer: No.

Fix: it only computes the right number and writes it into the native line lead time; Odoo keeps scheduling dates, moves and pickings exactly as before.

Where do the holidays come from?

Answer: From time off.

Detail: both the global time off (not tied to any calendar) and the selected calendar's own time off are excluded from the count.

What if I add a line afterwards?

Answer: Use Recalculate.

Detail: the small Recalculate button next to the field re-applies the value to every storable line, including ones added later.

Which lines get the value?

Answer: Storable ones.

Detail: only storable (deliverable) product lines are filled; services, sections, notes and down payments are skipped.
