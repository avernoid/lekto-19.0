Technical Specification for AI & LLM

This Odoo module 'universal_connector' provides a centralized configuration hub for third-party connector modules. It creates a dedicated "Connectors" app in Odoo's home menu with a unified Settings page where each connector module (e.g., openclaw_connector) can register its credentials via XPath extension. The module extends res.config.settings to provide the foundation model. Connector modules inherit the view and add their own credential fields. Admin-only access via base.group_system. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). NOT supported on Odoo Online due to custom code restrictions. Multi-language support for English and Spanish included.

Universal Connector

Centralized Integration Settings Hub

One place to manage all your third-party connector credentials. Install connector modules and configure them from a single, organized settings page under the Connectors app.

What We're Solving

----------------

Scattered Settings

Without a central hub, each connector module creates its own settings page. Administrators waste time hunting through menus to find and configure API keys, tokens, and credentials for different integrations.

Unified Configuration

Universal Connector provides a single Connectors app with a shared Settings page. Every connector module automatically appears here when installed, giving you a clean, organized overview of all your integrations.

Setup & User Manual

Step-by-Step implementation

1. Installation

Get started in 2 simple steps:

  • Install Universal Connector from the Apps menu.
  • A new Connectors app appears on your home screen.
  • Install any connector module (e.g., OpenClaw Connector).
  • Its settings automatically appear under Connectors > Configuration > Settings.
How it works: Each connector module extends the shared settings view via XPath. No manual configuration needed — just install and go.

2. How It Works

Architecture designed for scalability:

Dedicated App

The Connectors app appears on the Odoo home screen, providing a clear entry point for all integration management. Only System Administrators can access it.

Unified Settings

All connector credentials live on a single Settings page. Each connector module adds its own section automatically when installed. No scattered menus, no hunting for config pages.

Modular by Design

Universal Connector is the foundation. Each integration (OpenClaw, payment gateways, shipping providers, etc.) is a separate module that plugs into this hub. Install only what you need.

Admin-Only Access

Connector credentials are sensitive. Access is restricted to the System Administration group (base.group_system), ensuring only authorized personnel can view or modify API keys.

Global Ready | Multi-Language Support

This module is fully translated into English and Spanish (en_US, es_ES, es_PE, es_MX), ensuring a professional experience for international organizations.

FAQ & Troubleshooting

Common Resolutions

I don't see the Connectors app?

Reason: The app is restricted to System Administrators.

Fix: Ask your administrator to grant you the Settings access right, or have them configure the connector credentials for you.

Settings page is empty?

Reason: Universal Connector is a foundation module. It provides the hub; connectors provide the content.

Fix: Install one or more connector modules (e.g., OpenClaw Connector) from the Apps menu. Their settings will appear automatically.

Can I build my own connector?

Answer: Yes!

Detail: Create a new module that depends on universal_connector and extend the settings view via XPath. Your fields will appear automatically in the Connectors settings page.

Is this compatible with Multi-company?

Answer: Yes!

Detail: Connector settings follow Odoo's standard res.config.settings behavior, which supports per-company configuration out of the box.
