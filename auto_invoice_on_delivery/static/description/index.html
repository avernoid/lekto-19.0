Auto Invoice on Delivery

Streamline billing by creating invoices directly from delivery orders.

Accelerate invoicing, reduce manual steps, and automate billing upon delivery validation.

What We're Solving

----------------

Delayed Billing Cycles

In many businesses, the warehouse team ships goods, but the accounting team isn't notified immediately. This module allows triggering the invoice immediately upon delivery, speeding up payment collection.

Unnecessary Navigation

Standard Odoo requires navigating back to the Sales Order to create an invoice. This module adds the convenience of doing it directly from the Delivery Order, saving time and clicks.

Missed Invoices

With the automatic "On Validate" feature, you ensure that no delivery goes uninvoiced. As soon as the goods leave the warehouse, the invoice process begins automatically.

Overview

----------------

This module extends Odoo's Inventory and Sales capabilities by linking the delivery process directly to invoicing. It allows you to configure specific Operation Types (like Delivery Orders) to display a "Facturar" (Invoice) button.

Additionally, it offers an automation feature where validating a delivery order automatically triggers the invoice creation, ensuring a seamless flow from stock to cash. It uses the standard Sales Order invoicing logic, so it respects your existing invoicing policies (ordered vs delivered quantities).

Easy Setup

----------------

  1. Navigate to Inventory > Configuration > Operations Types.
  2. Select the operation type you want to configure (e.g., Delivery Orders).
  3. Locate the Facturación (Invoicing) section.
  4. Check Emitir Factura to enable the manual invoice button on pickings.
  5. (Optional) Check Al Validar to enable automatic invoicing when the picking is validated.

Workflow Guide

----------------

Manual Invoicing

  • Open a Delivery Order that is ready to be processed.
  • Click the Facturar button in the header.
  • The invoice will be created (or the wizard will open) based on the linked Sales Order.

Automatic Invoicing

  • Process the Delivery Order as usual.
  • Click Validate.
  • The system will automatically trigger the invoice creation immediately after validation.
