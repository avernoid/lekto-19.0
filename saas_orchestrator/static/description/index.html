Technical Specification for AI & LLM

This Odoo module 'saas_orchestrator' provides a complete SaaS lifecycle management engine for Odoo 19. It manages tenants, product blueprints, plans, and instances through integration with the Orquestio orchestrator API. Features include automatic instance provisioning on subscription confirmation, health monitoring, custom domain support via Cloudflare, operation dispatching (upgrade, restart, rotate_password, update_env_var), subscription-based suspension/destruction, and task history tracking. Compatible with Enterprise (Odoo.SH, Ganemo Online, Ganemo.SH). Multi-language support for English and Spanish included.

SaaS Orchestrator

Complete SaaS Instance Lifecycle Control

Provision, monitor, and manage Odoo SaaS instances through seamless integration with the Orquestio orchestrator API. Full lifecycle control from subscription to destruction.

What We're Solving

----------------

One-Click Provisioning

Automatically create and provision SaaS instances when a subscription order is confirmed. Tenants are created on-demand, and instances spin up automatically without manual intervention.

Real-Time Health Monitoring

Track CPU, RAM, and disk usage for each instance. Color-coded freshness indicators (Fresh/Stale/Missing) help identify instances that haven't reported in recently.

Blueprint-Driven Operations

Define operations (upgrade, restart, rotate password, update env vars) in the blueprint catalog. Dispatch them via intuitive wizards directly from the instance form.

Custom Domain Support

Customers can connect their own domain via Cloudflare for SaaS. Manage DNS and TLS certificate status directly from the Odoo interface with BYO custom domain wizard.

Setup & User Manual

Step-by-Step implementation

1. Initial Configuration

Configure the orchestrator connection in 3 simple steps:

  • Go to Settings > General Settings.
  • Find the SaaS Orchestrator section.
  • Enter the Orchestrator URL (e.g., https://api.orquestio.com).
  • Enter the API Key from your orchestrator account.
  • Click Test Connection to verify.
  • Save the settings.

2. Product Blueprints

Create a blueprint for each product type you offer:

Basic Information

Define the product domain (e.g., orquestio.com), Docker image, Terraform module, and health check endpoint.

Operations Catalog

Declare available operations (upgrade, restart, etc.) with script paths, timeouts, and required parameters. These drive the button visibility on instances.

3. Product Plans

Link plans to blueprints with tier-specific settings:

Instance Type

Specify EC2 instance type (e.g., t4g.small).

Storage

Configure included storage (GB) and extra storage pricing.

History Settings

Set retention days and max records for operation history.

FAQ & Troubleshooting

Common Resolutions

Connection to Orchestrator Failed?

Reason: The Orchestrator URL or API Key is incorrect or the service is unreachable.

Fix: Go to Settings > General Settings, verify the SaaS Orchestrator configuration, and test the connection.

Instance Won't Provision?

Reason: The instance may already exist, or the subscription is not linked to a SaaS plan.

Fix: Ensure the product template has a SaaS Plan assigned, and that the subscription order is confirmed.

Operations Buttons Not Visible?

Reason: The blueprint for the instance's plan does not declare those operations.

Fix: Go to the blueprint linked to the instance's plan, and add the corresponding operation entries in the Operations tab.

Custom Domain Pending Forever?

Reason: DNS propagation or certificate issuance may be delayed.

Fix: Click "Refresh Custom Domain" on the instance form to check the latest status from Cloudflare.
