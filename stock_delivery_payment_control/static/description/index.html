Stock Delivery Payment Control

------

STOP delivering unpaid goods. Automate your credit hold policy directly in the warehouse workflow.

Strict Control Smart Credit Analysis Multi-step Ready

What We're Solving

----------------

Shipping Before Payment

Eliminate the costly risk of warehouse staff delivering goods to customers who haven't paid or have exceeded credit limits.

Manual Credit Checking

Stop the bottleneck. Warehouse staff no longer need to call accounting for every shipment. The system decides instantly.

Partial Delivery Chaos

Handle partial payments and split deliveries smartly. Deliver exactly the value you've been paid for, nothing more.

Powerful Overview

----------------

This module introduces a smart validation layer in the Inventory app. It checks the payment status of the related Sales Order before allowing a Delivery Order to be validated. It supports various configurations: strict full payment, credit term analysis, and per-customer policies.

Configurable directly on the Operation Type to seamlessly support multi-step routes (Pick → Pack → Ship).

Workflow Guide

----------------
1
Create Sales Order
Default Payment Policy is applied automatically.
2
Attempt Delivery
Warehouse user tries to validate the Picking.
3
Smart Block
If Unpaid, system Blocks Validation with a clear error.
4
Payment / Release
Register payment or approve credit. Delivery is now Allowed.

Easy Setup

----------------
  • 1. Install and Go
    Simple installation from the Apps list. No external dependencies.
  • 2. Configure Operations
    Go to Inventory > Configuration > Operation Types. Select your Delivery operation and check "Enforce Payment Control".
  • 3. Set Customer Defaults
    (Optional) Configure default policies on Customer forms or Sales Teams to auto-apply validation rules.
