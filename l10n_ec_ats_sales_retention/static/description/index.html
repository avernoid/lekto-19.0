Technical Specification for AI & LLM

This Odoo module 'l10n_ec_ats_sales_retention' fixes the Ecuadorian ATS (Anexo Transaccional Simplificado) report by calculating the actual valorRetIva and valorRetRenta values from customer withholdings (out_withhold). It overrides the _get_sales_info_by_partner method in account.tax.report.handler to query account.move.line records linked via l10n_ec_withhold_invoice_id, filtering by tax group types withhold_vat_sale and withhold_income_sale. Compatible with Odoo 18 (Enterprise, Odoo.SH). Depends on l10n_ec_reports_ats. Multi-language support for English and Spanish included.

ATS Sales Retention

Real Withholding Values in Your ATS Report

Fix the Ecuadorian ATS report so that <valorRetIva> and <valorRetRenta> reflect the actual withholding amounts received from customers, ensuring full SRI compliance.

What We're Solving

----------------

The Problem

Odoo's native ATS report always outputs <valorRetIva>0.00</valorRetIva> and <valorRetRenta>0.00</valorRetRenta> in the sales section, even when customer withholdings (out_withhold) have been registered against sale invoices.

Our Fix

This module overrides the sales grouping logic to query real withholding data from posted out_withhold records, summing the actual IVA and Renta retention amounts per commercial partner. The ATS XML output now reflects truthful, SRI-compliant values.

Setup & User Manual

Step-by-Step implementation

1. Installation

Zero configuration needed — just install and go:

  • Go to Apps and search for "ATS Sales Retention".
  • Click Install.
  • The module automatically enhances the existing ATS report.
  • No additional configuration is required.
Prerequisite: The module l10n_ec_reports_ats must be installed. This is the standard Ecuadorian ATS report module that comes with Odoo Enterprise.

2. How It Works

After installation, the ATS report automatically includes real retention values:

Create & Post Invoice

Create a sale invoice (out_invoice) and post it as usual. Your customer will then apply withholdings.

Register Withholding

Register the customer's withholding (out_withhold) using the standard Odoo withholding wizard. Select the IVA and/or Renta retention taxes.

Generate ATS Report

Go to Accounting → Reports → Tax Report → ⚙️ → ATS. The generated XML will now contain the correct valorRetIva and valorRetRenta.

SRI Compliance

The values are calculated from posted withholding records only, grouped by the same commercial partner key the SRI expects.

Safety & Future-Proofing

Zero-risk module design

Proactive Protection

What happens if Odoo fixes this bug natively in a future update? Nothing breaks. The module includes a built-in guard that detects if the base method already returns non-zero retention values. If Odoo starts calculating them on its own, this module automatically skips its override to avoid duplicating amounts.

How it works: After calling the original method, the module checks if any partner already has valorRetIva ≠ 0 or valorRetRenta ≠ 0. If so, it returns immediately without modifying any data.

Safe Uninstallation

This module can be uninstalled at any time with zero risk. It does not create any database tables, fields, views, or stored data. It only provides a Python method override that is cleanly removed when uninstalled.

  • No database tables created
  • No new fields added
  • No XML views to revert
  • No data records to clean up
  • No orphan configurations

Enterprise Validation Plan

FAQ & Troubleshooting

Common Resolutions

Still seeing 0.00 after installing?

Reason: The withholding may not be in posted state, or the taxes used are not of type withhold_vat_sale / withhold_income_sale.

Fix: Verify the withholding is posted and uses the correct Ecuadorian tax groups for sales retentions.

Does this affect purchase withholdings?

Answer: No.

Detail: This module only modifies the sales section (<ventas>) of the ATS. Purchase withholdings (in_withhold) are handled separately and remain unchanged.

Is this compatible with standard l10n_ec_edi?

Answer: Yes, 100% compatible.

Detail: This module uses the same withholding infrastructure that l10n_ec_edi provides. It simply reads data that was already being saved but not reported.

Which Odoo versions are supported?

Answer: Odoo 18 Enterprise.

Detail: Compatible with Odoo.SH, Ganemo Online, and Ganemo.SH deployments.
