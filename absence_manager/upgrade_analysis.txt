---Code changes in module 'absence_manager'---

1. DEL override _compute_last_attendance_id  (hr.employee)
   REASON: The override prioritized open attendance records (without check_out)
   over the most recent one. However:
   - The module NEVER reads last_attendance_id in any of its own logic.
   - The CRON (_action_absence_monitor) searches hr.attendance directly by
     employee and date range — it does not use last_attendance_id.
   - action_approve, action_refuse, write, create_attendance_period — none
     of these methods reference last_attendance_id.
   - Odoo 19 native implementation uses order="check_in desc" which already
     handles the edge case correctly.
   - The override could cause subtle bugs in the native attendance kiosk
     because it lacked explicit ordering in its search.
   ACTION: Removed the override entirely. Native Odoo behavior restored.
   RISK: None — the field was never consumed by the module's own logic.

2. CHG default attendance=True → attendance=False  (hr.employee)
   REASON: With default=True, installing the module would immediately flag
   ALL existing employees for daily monitoring, generating false PPD absences
   for employees who are not expected to clock in (freelancers, managers, etc.).
   ACTION: Changed to default=False so monitoring is opt-in per employee.
   RISK: None for existing records — the default only affects NEW employees
   created after the update. Existing employees retain their current value.

3. CHG unused imports removed  (hr_employee.py, hr_attendance.py, hr_leave_type.py)
   REASON: datetime, relativedelta, and api were imported but never used.
   ACTION: Cleaned up to only import fields, models (and api where needed).

---Impact on existing databases---
IMPORTANT: No data migration needed.
- The _compute_last_attendance_id removal restores native Odoo behavior.
  Existing attendance records are unaffected.
- The default=False change only applies to NEW employee records.
  Employees already marked with attendance=True will KEEP their value.

---Files changed---
MODIFIED models/hr_employee.py       (removed override, changed default, cleaned imports)
MODIFIED models/hr_attendance.py     (cleaned unused imports)
MODIFIED models/hr_leave_type.py     (cleaned unused imports)
