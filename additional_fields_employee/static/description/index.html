Technical Specification for AI & LLM

This Odoo module 'additional_fields_employee' extends hr.employee and hr.version with fields for Academic Degree (academic.degree), Health Regime (health.regime), Labor Regime (employee.regime), Labor Condition / Contract Type (type.contract), Work Occupation (work.occupation). Also adds labor flags: maximum working day, atypical cumulative day, nocturnal schedule, unionized, and is practitioner. All fields use hr.version delegation for versioned employee data. Includes pre-loaded reference data for Peruvian payroll compliance (SUNAT codes). Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). NOT supported on Odoo Online due to custom code restrictions. Multi-language support for English and Spanish included.

Employee Fields

Extended Data & Peruvian Compliance

Enrich employee records with academic degrees, health regimes, labor regimes, work occupations, and contract types — all aligned with Peruvian payroll requirements (SUNAT).

What We're Solving

----------------

Academic & Health Data

Standard Odoo employee forms lack fields for Academic Degree and Health Regime. This module adds dedicated relational fields with pre-loaded Peruvian reference data, so HR teams can track educational background and health coverage without manual configuration.

Labor Regime & Contract Type

Peruvian payroll requires tracking the employee's Labor Regime (private/public sector, MYPE), Contract Type, and Work Occupation. These fields come pre-loaded with SUNAT-compliant codes and are ready to use from day one.

Work Condition Flags

Track special labor conditions: Maximum Working Day, Atypical/Cumulative Schedule, Nocturnal Shift, Unionized, and Practitioner status. Essential for accurate payroll calculation and legal reporting.

Setup & User Manual

Step-by-Step implementation

1. Reference Data Configuration

Configure the catalogs that power the employee fields:

  • Go to Peruvian Localization > Configuration > Academic Degrees to manage educational levels.
  • Go to Peruvian Localization > Configuration > Health Regimes to manage health coverage types.
  • Go to Peruvian Localization > Configuration > Labor Regimes to manage employment regimes.
  • Go to Peruvian Localization > Configuration > Contract Types to manage contract classifications.
  • Go to Peruvian Localization > Configuration > Work Occupations to manage job categories.
Pre-loaded Data: All catalogs come pre-loaded with official Peruvian (SUNAT) codes. You can add, edit, or deactivate entries as needed.

2. Using the Employee Form

How to fill in the extended employee data:

Personal & Academic Tab

Open any employee record. In the dedicated section you will find Academic Degree and Health Regime dropdowns. Select the appropriate values from the pre-loaded catalogs.

Labor Information

Set the Labor Regime, Labor Condition, and Work Occupation. Toggle the boolean flags for nocturnal schedule, maximum working day, atypical shifts, unionized status, and practitioner status.

Version Tracking

All fields leverage the hr.version delegation pattern. This means every change is tracked and versioned, ensuring a complete audit trail of employee data modifications.

FAQ & Troubleshooting

Common Resolutions

Fields not visible on the employee form?

Reason: You may not have the HR Officer role.

Fix: All extended fields require the hr.group_hr_user group. Ask your Administrator to assign you the "HR Officer" role.

Catalog dropdowns are empty?

Reason: Reference data may not have loaded during installation.

Fix: Go to Apps, find the module, and click Upgrade. This will reload all pre-configured SUNAT data.

Is this compatible with multi-company?

Answer: Yes!

Detail: All fields are tied to the employee record, which inherently follows Odoo's multi-company rules. Each company's employees have independent data.
