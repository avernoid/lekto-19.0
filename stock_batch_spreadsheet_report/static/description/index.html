User Manual & Guide

Everything you need to configure and use the module efficiently.

1. Designing Templates

The power of this module lies in its templates. You only do this once.

  1. Go to Inventory > Config > Batch Spreadsheets > Templates.
  2. Click New. Give it a name (e.g., "Packing List").
  3. The Magic Step: An empty spreadsheet opens. Use the "Data" menu (top bar) or right-sidebar to access Odoo Data.
  4. Select "Batch Transfer" as your source. Drag & Drop fields like Name, Scheduled Date, or list data like Move Lines into cells.
  5. Save: Your changes are auto-saved. This template is now the "Master" for all future reports.

2. Daily Operation

Instructions for your Warehouse Team.

  1. Open any Batch Transfer record.
  2. Look for the "Reports" Smart Button (Top Right).
    0 Reports = Nothing created yet.
  3. Click It: The system instantly copies your Template, fills it with THIS Batch's data, and opens it.
  4. Print/Share: Use the standard File > Print or Download options inside the spreadsheet if you need a PDF or Excel file.

Advanced & Troubleshooting

How to Reset / Re-create a Report?
If a report has errors or you changed the template and want a fresh version:
  1. Open the current Report.
  2. Go to File > Move to Trash (Archive).
  3. Go back to the Batch. The button now says "0 Reports".
  4. Click it again to generate a new one.
How to Empty Trash?
To permanently delete archived reports:
  • Go to Inventory > Config > Batch Spreadsheets > Spreadsheets Data.
  • Use the Filter "Archived".
  • Select records and Delete.
