Setup & User Manual

Step-by-Step implementation

1. Detailed Configuration Guide

Follow these steps to perfectly configure your automated POS workflow:

  • Step A: Navigate to Point of Sale > Configuration > Settings.
  • Step B: Locate the section titled "Receipt & Invoices". This module seamlessly integrates into Odoo's native configuration structure.
  • Step C: You will see two new options:
    • Automatic Electronic Invoice Printing: When checked, the system bypasses the native receipt screen if an invoice is requested, launching the formal PDF print dialog directly.
    • Automatic Electronic Invoice Download: When checked, a PDF copy of the invoice will be saved to the cashier's computer immediately after validation.
  • Pro-Tip: If you enable invoice auto-print, the system will automatically disable the "Automatic Receipt Printing". This is intentional to prevent the cashier from wasting paper by printing a simple receipt and then a formal invoice for the same transaction.

2. Operating Manual (Cashier Workflow)

The daily routine of a cashier becomes faster and more reliable:

1. Cart Validation

Add products to the cart as usual. When proceeding to payment, identify if the customer requires an Invoice.

2. Invoice Selection

Click the "Invoice" button in the payment screen. This activates the specialized technical triggers of this base template.

3. Auto-Automation

Upon clicking "Validate", the module detects the "Invoice" state and executes the Print/Download actions without extra clicks.

Wait for PDF Generation: Ensure the cashier is aware that for very large invoices, there might be a split-second delay while Odoo generates the official PDF document before the print dialog appears.

QA / User Testing Scenarios

Enterprise Validation Plan

Scenario 1: Automatic Printing Compliance

Goal: Verify that the invoice reaches the printer without manual steps.

  1. Enable Automatic Electronic Invoice Printing.
  2. Select a Customer and mark the Invoice flag.
  3. Validate the payment.
  4. Expected Result: The browser opens the print dialog immediately. No extra "Print Invoice" button click is required.

Scenario 2: Smart Exclusivity Safety

Goal: Prevent double document printing and paper waste.

  1. Check if "Automatic Receipt Printing" is ON. Then enable "Automatic Electronic Invoice Printing".
  2. Verify that the POS now only shows the Invoice printing as active.
  3. Complete a sale with an invoice.
  4. Expected Result: Only the formal invoice is printed. The native internal receipt is skipped, saving thermal paper.

Scenario 3: Massive Digital Archiving

Goal: Validate back-to-back download performance.

  1. Enable Automatic electronic invoice download.
  2. Perform 5 rapid sales with invoice requested.
  3. Expected Result: The browser downloads folder should contain 5 separate PDF files, correctly named after the Odoo sequences.

Scenario 4: Mixed Cart Logic

Goal: Verify behavior when Invoice is NOT selected.

  1. Keep Auto-Invoice-Print enabled.
  2. Perform a sale but do NOT select the "Invoice" button.
  3. Validate the payment.
  4. Expected Result: The module should remain silent. Only the native receipt logic (if enabled) should execute. This proves the "Base Template" target specificity.

FAQ & Troubleshooting

Common Resolutions

Why didn't my invoice print automatically?

Resolution: Check that the "Invoice" button was actually blue (selected) on the payment screen. Also, ensure your browser does not have a "Pop-up Blocker" preventing the print window from launching.

The native receipt isn't printing anymore. What happened?

Answer: This is a safety feature. High-end businesses avoid giving the customer two documents for the same sale. If you need both, you will need a custom override. By default, this module prioritizes the formal invoice.

Does it support Odoo standard PDF reports?

Absolutly: It uses the standard Odoo report engine. If you customize your Invoice report in the backend, it will automatically reflect in the POS printout via this module.

Does it work with "Print.js"?

Yes: We include the library internally to ensure the PDF is handled as a visual document and not just a text stream, ensuring professional typography and layout.
