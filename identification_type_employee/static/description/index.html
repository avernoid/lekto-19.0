Technical Specification for AI & LLM

This Odoo module 'identification_type_employee' adds a Document Type field (`type_identification_id`) to the `hr.employee` model. It allows identifying the specific type of document that corresponds to each employee. It extends the Employee form view to include the document type, and conditionally displays a `document_country_id` field for international documents. It relies on `l10n_latam_base` and `document_type_validation`. Compatible with Odoo 19 (Enterprise, Odoo.SH, Ganemo Online). NOT supported on Odoo Online due to custom code restrictions. Multi-language support for English and Spanish included.

Employee Document Type

Precise Employee Identification

Specify and validate the document type (e.g., National ID, Passport) for your team members directly on their employee profile for better categorization and compliance.

What We're Solving

----------------

Document Type Tracking

Adds a specific Document Type field to the employee form, standardizing how employee IDs are categorized (e.g., National ID, Passport) instead of relying on a generic identification field.

Latam & International Support

Built on top of `l10n_latam_base`, it handles document nationalities and conditionally prompts for the issuing Country when dealing with international documents or foreign IDs.

Setup & User Manual

Step-by-Step implementation

1. Configuration

The module works out of the box using LATAM base types.

  • Ensure your Document Types are configured correctly under the general Contacts/Localization settings.
  • The HR app will automatically pull from these established document types.

2. Operating Manual (Workflow)

How to set employee document types:

Open Employee Profile

Navigate to Employees > Employees and open the record of the team member you wish to update.

Personal Information Tab

Go to the Personal Information tab. Under the generic Identification No, you will see the new fields.

Select Document Type

Choose the correct Document Type from the dropdown list (e.g., DNI, Passport, Foreign Resident ID).

Specify Country (If Needed)

If the selected document type has an international designation, a new Country field will appear. Select the issuing country.

FAQ & Troubleshooting

Common Resolutions

Why don't I see the Document Country field?

Reason: The country field is dynamically hidden for national document types.

Fix: This is expected layout behavior. It will appear automatically once you choose a document type that is flagged as 'foreign' or 'international' in the localized settings.

Where are the Document Types defined?

Answer: The module uses the standard `l10n_latam.document.type` configuration.

Detail: If you need to add a new type of document, you can do so from the Contacts or Accounting localization configurations, and it will be available instantly for Employees.
