DOCUMENTATION

User Manual & Guide

Module Configuration

The Localization Menu module is designed for simplicity. It does not require a dedicated settings page. Instead, it relies on the user (Auditor, Accountant, or Manager) to populate the master tables required for peruvian fiscal operations.

Prerequisites
  • Odoo "Accounting" app installed.
  • User must have "Accountant" or "Advisor" permissions to view configuration menus.
OPERATIONS

Workflow Guide

Integrate the localization menu into your daily accounting routine effortlessly.

1
Accessing the Hub

Navigate to Accounting > Configuration > Localization. You will see the new centralized menu structure.

2
Managing Spot Detractions

Go to Localization > Spot Detractions to create or update detraction types (e.g., "027 - Hormigón"). Ensure the correct percentage and account codes are set according to current SUNAT regulations.

3
Updating Customs Codes

For importers, navigate to Localization > Customs Codes. Verify that the dependency codes (e.g., "118 - Marítima del Callao") match your Import Declarations (DUA).

QA / User Testing Scenarios

Use these scenarios to validate the module implementation in your staging environment.

Scenario A: Menu Visibility

Step 1: Log in as an "Accountant" user.

Scenario B: Data Entry (Detractions)

Expected Result: The record is saved without errors and appears in the list view.

Scenario C: Access Control

Step 1: Log in as a standard "User" (not Accountant/Advisor).
Step 2: Attempt to access Accounting > Configuration.
Expected Result: The user should NOT see the configuration menus or modify localization tables, ensuring data integrity.
