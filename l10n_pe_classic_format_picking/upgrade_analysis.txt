---Changelog (Session 2026-02-11)---

### New Features
1. **Per-Operation-Type Lot/Serial Column** (`show_lot_on_eguia`):
   - New Boolean field on `stock.picking.type`.
   - Controls whether the Lot/Serial column appears on the e-Guía report.
   - Template variable `show_lot_col = has_serial_number and picking_type.show_lot_on_eguia`.
   - Includes fallback: if global group `stock.group_lot_on_delivery_slip` is inactive
     but the per-operation-type boolean IS enabled, lots are still checked independently.

2. **Per-Operation-Type Expiration Date Column** (`show_expiry_on_eguia`):
   - New Boolean field on `stock.picking.type`.
   - Requires `show_lot_on_eguia` to be enabled (both in UI visibility and logic).
   - Template variable `show_expiry_col = show_lot_col and picking_type.show_expiry_on_eguia`.

### Report Template Changes (ticket_template.xml)
1. **Header Standardization**:
   - First column header renamed from "ITM" to "N°" in the done-state header.
   - Expiry column header set to "Exp. Date" (English source; Spanish "F. Exp." via .po files).

2. **Conditional Column Headers** (4 branches):
   - `show_lot_col AND show_expiry_col`: N°(4%) + Producto(49%) + Lote/Serie(11%) + Exp.Date(11%) + Cant.(9%) + Udm(8%) + Peso(8%)
   - `show_lot_col` only: N°(4%) + Producto(58%) + Lote/Serie(13%) + Cant.(9%) + Udm(8%) + Peso(8%)
   - `show_expiry_col` only: N°(4%) + Producto(58%) + Exp.Date(13%) + Cant.(9%) + Udm(8%) + Peso(8%)
   - Default (none): N°(4%) + Producto(71%) + Cant.(9%) + Udm(8%) + Peso(8%)

3. **Row Sub-Template** (`stock_report_delivery_has_serial_move_line_1`):
   - Same 4 branches with matching column widths.
   - Each branch renders appropriate fields (lot_id.name, lot_id.expiration_date, etc.).

4. **Package Grouping Fix**:
   - Changed `class="row-values"` → `class="row"` in the package+lot branch.
   - `row-values` lacked `display: flex`, causing columns to stack vertically inside packages.
   - `row` has `display: flex` defined in CSS, fixing the horizontal layout.

---Gotchas & Lessons Learned---
1. **groups attribute on t-set**: The `groups="stock.group_lot_on_delivery_slip"` attribute on
   `<t t-set="has_serial_number">` prevents execution if the global Inventory setting is off.
   Added a fallback block that bypasses the groups check when the per-operation-type boolean is enabled.

2. **row-values vs row CSS class**: The `row-values` class does NOT have `display: flex`.
   When using sub-templates that output column divs directly (not wrapped in their own row div),
   the parent MUST use `class="row"` for proper horizontal layout.

3. **Font-size inheritance**: Inline `font-size: 14px` on some columns but not others causes
   visual inconsistency when the container has a different default (16px). Fix at the CSS
   container level rather than adding inline overrides to every div.
