Menu Visibility Manager

------

Hide specific menu items for selected users to improve security and usability.

Simplify the Odoo interface by hiding irrelevant menus for specific users, ensuring a cleaner workspace and better access control.

What We're Solving

----------------

Cluttered Interfaces

Junior staff often see too many menus they don't need, leading to confusion. Clean up their view instantly.

Sensitive Configs

Grant module access (like Inventory) but hide specific configuration menus that should only be touched by managers.

Granular Control

Hide specific items without creating complex new security groups. Simple, direct, and effective.

Overview

This module empowers administrators to fine-tune menu access rights with ease. You can hide specific menus for individual users or exclude users from specific menus directly from the menu configuration. This bi-directional synchronization ensures easy management and robust security.

Easy Setup

----------------

1

From User Form

Go to Settings > Users & Companies > Users. Open a user, navigate to the "Hidden Menus" tab, and simply add the menus you want to hide.

2

From Menu Form

Go to Settings > Technical > User Interface > Menu Items. Open a menu, go to the "Excluded Users" tab, and add the users you want to restrict.

Changes are automatically synchronized between both views!

Workflow Guide

----------------

  • Immediate Effect
    When the restricted user logs in or refreshes their browser, the hidden menus will no longer be visible to them.
  • Admin Safety
    Administrators and Superusers will always see all menus, ensuring they never lose access to configuration settings.
  • Auto-Cleanup
    If a user's permissions change (e.g., they are no longer an internal user), their hidden menu settings are automatically cleared to prevent data inconsistency.
